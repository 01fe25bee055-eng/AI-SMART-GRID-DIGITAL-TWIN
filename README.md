AI-Powered Smart Grid Digital Twin

Project Overview

This project demonstrates a smart grid monitoring system using ESP32, sensors, relays, and a digital dashboard.

Objectives

- Monitor voltage, current, and transformer temperature.
- Detect normal, overload, and fault conditions.
- Display real-time measurements and alerts.
- Simulate grid conditions using a digital twin.
- Explore AI-based anomaly detection and fault prediction.

Hardware Components

- ESP32 development board
- ZMPT101B voltage sensor
- ACS712 current sensor
- DS18B20 temperature sensor
- LDR light sensor
- OLED display
- Two-channel relay module
- Push buttons
- Transformer and low-voltage demonstration loads

Project Modules

1. Sensor data acquisition
2. Grid status monitoring
3. Fault detection
4. Relay-based load control
5. Dashboard visualization
6. AI anomaly detection and prediction
